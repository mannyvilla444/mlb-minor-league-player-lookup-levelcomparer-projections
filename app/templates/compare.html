OPS and SLG differences are in points; BB% and K% differences are in percentage points (a 22.0% K% against 18.0% shows as +4.0, not +22%). Green means the bat was better at the higher level and red worse — so on K%, where fewer is better, the colours flip. n is counted per column: a player can have a usable ΔOPS but no ΔBB% if the API omitted walks on one side. SD is how spread out the players are; SE is how precisely the centre itself is pinned down — a big SD with a small SE means a noisy population but a well-estimated average. The median's SE is bootstrapped rather than assuming a normal distribution, and it is seeded, so reloading the page never changes it. {% if result.excluded_count %} {{ result.excluded_count }} row{{ '' if result.excluded_count == 1 else 's' }} greyed out and left out of the summary. {% endif %}
